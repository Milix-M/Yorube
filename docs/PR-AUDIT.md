## 共通部分の修正

- `run.queued` などの非終端イベントでSSEを閉じないように変更。
- SSEの送信バッファが埋まった場合は待機し、フレームを破棄しないように変更。
- 購読キャンセル時に、レスポンスヘッダー待機中でもHTTP接続を閉じるように変更。
- `Last-Event-ID` で受信済みの続きから再接続。終端の最終出力で表示を確定。
- 復元時に再送された承認・質問が回答済みか、サーバーの状態と世代番号で確認。
- 画面を離れたあとも、受理済み実行の監視とキューの処理を継続。失敗・中断・結果不明のあとには次のプロンプトを自動送信しない。
- 接続先と会話ごとにキューを保存。設定保存時に、別の操作が更新した会話の所有情報やピン留めを上書きしないように変更。
- 設定画面の接続テストが、保存済みの接続先ではなく編集中の値を使うように変更。
- Linux ARM64上でRobolectricのネイティブテストを実行できるよう、公式配布のARM64ライブラリを読み込むテスト用ローダーを追加。
- JaCoCoのクラス参照先をAGP 9の出力先へ修正。対象クラスが0件でも検証が成功していた問題を修正。
