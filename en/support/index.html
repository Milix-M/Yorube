Support

Report bugs and suggest features through GitHub Issues.

GitHub Issues

Connection problems

  1. Check that your device can reach the server URL.
  2. Verify the API key and, if required, the Cloudflare Access credentials.
  3. Save the settings, then run the connection test.
  4. For notification or background problems, check Android permissions and battery settings.

What to include in a report

Include the app version, Android version, steps to reproduce the problem, expected behavior and actual behavior. Review debug logs before sharing them.

GitHub issues are public.

Do not paste API keys, Client Secrets, private conversations, personal information or internal server details.

Server questions

For model charges, deleting server-side data and logs, or issues specific to your connection endpoint, contact the server operator or the relevant service provider.
