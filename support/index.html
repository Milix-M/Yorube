サポート

不具合の報告や機能の提案は、GitHub Issuesで受け付けています。

GitHub Issuesを開く

接続できないとき

  1. 端末からサーバーのURLに接続できるか確認します。
  2. APIキーと、必要な場合はCloudflare Accessの認証情報を確認します。
  3. 設定を保存してから接続テストを実行します。
  4. 通知やバックグラウンド動作の場合は、Androidの権限・省電力設定も確認します。

報告に添える情報

アプリのバージョン、Androidのバージョン、再現手順、期待した動作と実際の動作を添えると、調査しやすくなります。デバッグログを共有する場合は内容を確認してください。

Issueは公開されます。

APIキー、Client Secret、会話内容、個人情報や内部サーバーの情報をそのまま貼り付けないでください。

サーバーに関すること

モデルの利用料金、サーバーの保存データやログの削除、接続先固有の問題は、サーバー運営者または利用するサービスの窓口に確認してください。
